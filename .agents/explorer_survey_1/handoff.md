## 2. Logic Chain

1. **Why Blind Dereference Causes 0xC0000005**:
   - When a game renders with native DXGI (`CDXGISwapChain`) or a third-party interposer (Streamline `sl.interposer.dll`, Reflex, Agility SDK, ReShade), `swap` is NOT an NvPresent64 proxy object.
   - At offset `[swap + 0x18]`, native DXGI or Streamline stores arbitrary internal class fields (integers, HWND handles, or non-COM pointers).
   - `sm86_rehost.cpp` treats this value as an object pointer `wrapper`, dereferences `*(void***)wrapper` to obtain a vtable, and calls `vt[19]` at offset `0x98`.
   - When `wrapper` is an integer or smaller object, dereferencing `*(void***)wrapper` or calling `vt[19]` triggers an unhandled `0xC0000005` access violation.
2. **Why VTable Comparison Eliminates Crashes**:
   - The proxy COM object generated by `NvPresent64.dll` has a unique vtable pointer at RVA `base + 0x1d3228`.
   - By pre-validating `*(void**)swap == (uintptr_t)g_nvpresent + 0x1d3228` before touching offset `+0x18`, non-NvPresent swapchains are immediately identified and bypassed.
   - Offset `+0x18` is never accessed on native or third-party swapchains.
3. **Safe Memory Probing Architecture**:
   - Under MSVC x64 C++17 with `/EHsc`, functions with C++ objects containing destructors trigger compiler error `C2712` if `__try / __except` is used.
   - Therefore, memory probing is isolated into a pure C-style static helper function (`SafeReadPointer`) combining address sanity checks (alignment, canonical 64-bit user range), `VirtualQuery` (to verify `MEM_COMMIT` and page read rights without triggering first-chance debugger stops), and hardware SEH (`__try / __except`) to protect against TOCTOU deallocation races.
4. **Third-Party Interposer Handling**:
   - In Streamline-enabled games, Streamline wraps NvPresent64's proxy swapchain (`m_base`). When Streamline calls `m_base->Present()`, our hook intercepts `m_base`, matches RVA `0x1d3228`, and activates Smooth Motion.
   - When our hook intercepts an outer Streamline or native swapchain, it immediately forwards to `g_origPresent` without modification.
